# Використання AI

Інструмент: Claude Code (Claude Opus) у Unity-проєкті через Unity CLI (пакет Unity Pipeline).

| Де | Що зробив AI | Що зробив я |
|---|---|---|
| Концепція | Розбір умов конкурсу і трейлера, варіанти механік, звуження обсягу до однієї системи (шланг + подача води) | Вибір концепції, рішення гідрант → машина → шланг |
| Налаштування AI | `CLAUDE.md`, правила `.claude/rules` (code style, архітектура), скіли бібліотек у `.claude/skills` | Вимоги до стилю й архітектури, перевірка |
| Каркас проєкту | Сцени Boot/Gameplay, `SceneLoader`, scope VContainer, `EntryPointSceneAutoLoader` (перенесено з мого проєкту Im-Not-a-spy) | Структура флову сцен, правки точок входу |
| Модель пожежної машини | Процедурна модель у Blender (Python-скрипт через Blender MCP) за моїми референсами, запікання в одну текстуру-палітру, FBX, імпорт у Unity: URP-матеріал, налаштування імпорту, префаб `FireTruck` | Референси машини, перевірка відповідності, правки (сходинка в колесі) |
| Вулиця | Процедурна low-poly вулиця за моїм референсом у масштабі машини (дорога 8 м, будинки, паркани, дерева, пропси), спільна палітра й один матеріал `Palette_Mat` для всіх моделей, колайдери, префаб `Street` | Референс, вимога до масштабу й одного матеріалу, закриття кінця вулиці |
| Будинок з інтер'єром | Двоповерховий будинок з отворами, сходами, меблями (кожен предмет — окремий об'єкт для фізики), дверима на петлях; колайдер на самій оболонці; префаб `HouseInterior`, вкладений у `Street` | Вибір будинку, вимоги до кімнат і другого поверху |
| Гідрант | Low-poly гідрант за моїм референсом (корпус, знімна заглушка, латунна муфта, точка кріплення шланга `Hydrant_HoseAttach`), колайдери, окремий префаб `Hydrant` | Референс, рішення тримати гідрант окремим об'єктом |
| Перевірка z-fighting | Скрипт-сканер співпадаючих граней (Python у Blender), виправлення всіх знайдених місць на машині, вулиці й будинку | Запит на перевірку |
